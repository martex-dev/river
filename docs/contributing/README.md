# Contributor guides

Start with [CONTRIBUTING.md](../../CONTRIBUTING.md) and [DEVELOPMENT.md](../../DEVELOPMENT.md).

- Commit messages: Conventional Commits (`feat(scope):`, `fix(scope):`, `security(scope):`, `docs:`, `build(release):`).
- Every change ships with tests; security-relevant code ships with negative tests.
- UI copy must be honest about what works today.
