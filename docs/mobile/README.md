# Mobile (Stage 2)

Native apps arrive during 1.3.x (iOS) and 1.4.x (Android) and reach parity in
**2.0.0**. Design: [ARCHITECTURE.md §13](../../ARCHITECTURE.md#13-mobile-architecture-stage-2-planned).

Distribution plan:

- **Android** — signed APK on GitHub Releases (auto-updatable through
  Obtainium), F-Droid, and Google Play if the maintainer opens a developer account.
- **iOS** — App Store / TestFlight require an Apple Developer account; without
  one, distribution is limited to sideloading and EU alternative marketplaces.
