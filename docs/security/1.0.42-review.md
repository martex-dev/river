# Security review — River 1.0.42

Scope: the Discord-style layout (rail, Home sidebar, Settings overlay, title
bar). Renderer-only change apart from the window's title bar height. Internal
review; not an independent audit.

| Area              | Check                                                                                                                                                                         | Result                                     |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| Renderer boundary | No new IPC, no new preload API, no new permissions; the renderer still has no Node access and the CSP is unchanged                                                            | ✅ `app.spec.ts` (CSP, no Node)            |
| Honest UI         | The Security Center moved into Settings → Security unchanged: it still shows only what is active and marks the rest as planned. The connection pill shows the real connection | ✅ `app.spec.ts`, `server.spec.ts`         |
| Admin             | Admin still appears only on the PC that hosts the server; other people never see it                                                                                           | ✅ `hosting.spec.ts`                       |
| Less exposure     | The River ID box on Home's message list is gone; nothing new is shown about anyone                                                                                            | ✅ review                                  |
| Accessibility     | Every screen and every Settings tab passes the WCAG 2.1 AA audit, including avatar colours and the microphone meter                                                           | ✅ `a11y.spec.ts`, `avatar-color.test.tsx` |

Residual risks: unchanged from 1.0.41 (home server tunnel drops; unsigned
Windows installer warns on first run). No critical issue is open for 1.0.42.
