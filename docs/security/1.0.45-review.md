# Security review — River 1.0.45

Scope: skins, themes and the personalisation centre. Internal review; not an independent audit.

| Area                | Check                                                                                                                                                                                                                                                   | Result                                 |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| No code in settings | Design settings, custom themes, profiles and imports are zod-validated data: hex colours, ids `[a-z0-9-]`, bounded numbers and enums. Nothing is inserted as CSS text or executed; values only become CSS custom properties through `style.setProperty` | ✅ `design-engine.test.ts`             |
| Background pictures | Only `data:image/png                                                                                                                                                                                                                                    | jpeg                                   | webp;base64` up to ~2 MB, chosen by the person from their own files; stays in local settings; SVG refused | ✅ `design-engine.test.ts` |
| Import              | Rejected unless it matches the export schema; merges without replacing existing themes/profiles; background pictures are never exported                                                                                                                 | ✅ `design-engine.test.ts`             |
| CSP unchanged       | Fonts are bundled (`font-src 'self'`); patterns are data URLs (`img-src data:` already allowed); no new network access                                                                                                                                  | ✅ review                              |
| Title bar colours   | New IPC accepts exactly two `#rrggbb` colours (zod) and only sets the window's title-bar overlay                                                                                                                                                        | ✅ review                              |
| Honest UI           | Every control changes something real; no placeholders. The security centre and connection pill are unchanged                                                                                                                                            | ✅ review, e2e                         |
| Readability         | The engine enforces WCAG AA for text and 3:1 for accents on every theme and under hostile colour choices                                                                                                                                                | ✅ `design-engine.test.ts` (118 cases) |

No critical issue is open for 1.0.45.
