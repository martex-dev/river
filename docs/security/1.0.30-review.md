independent audit.

| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| Role order      | Dragging only sends the existing `PATCH /roles/:id` position updates; the server still requires `MANAGE_ROLES` and refuses to move a role to or above the mover's highest role                                   | ✅ existing server tests    |
