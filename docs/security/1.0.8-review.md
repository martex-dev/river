# Security review — River 1.0.8

Scope: the server identity key and signed address notes, the app following a
moved server, River Host, start-at-sign-in and the tray, voice user limits, and
the fullscreen permission. Internal review; not an independent audit.

| Area                  | Check                                                                                                                                                                                                       | Result                         |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| Server identity key   | Ed25519 key created once and kept in `server_meta`; only the public key is served (`GET /v1/instance`)                                                                                                      | ✅ `instance.test.ts`          |
| Announcing an address | Accepted only from a loopback socket with **no** proxy headers (so nothing through the tunnel qualifies) and only with River Host's per-start token (constant-time compare); no token configured → no route | ✅ `instance.test.ts`          |
| Following a move      | The app accepts a note only if the pinned key signed it, then checks the new address answers with the same instance ID and key before moving; a pinned identity is never replaced silently                  | ✅ `locator.test.ts` (forgery) |
| Relay                 | Sees IPs and timing of posts and reads, and the (already public) tunnel address; no content, names or keys. Can be turned off. Documented in THREAT_MODEL §5a                                               | ✅ docs                        |
| River Host            | Runs as the signed-in user (no admin), token never written to disk, data outside the release copy, children stopped with the host                                                                           | ✅ code review                 |
| Tray / sign-in start  | `--hidden` only hides the window; start at sign-in is off by default and only set in installed builds                                                                                                       | ✅ code review                 |
| Fullscreen            | Permission allowed only for River's own UI origin, like media                                                                                                                                               | ✅ code review                 |
| Voice limits          | Enforced on the server when joining; people who may move members can still join                                                                                                                             | ✅ `communities.test.ts`       |

No critical issue is open for 1.0.8.
