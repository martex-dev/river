# Security review — River 1.0.25

Scope: favourite GIFs, group icons, per-community pictures, avatar crop,
screen share quality, followed threads, forum pin/close, slash commands.
Internal review; not an independent audit.

| Area                  | Check                                                                                                                                                                  | Result                       |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| Favourite GIFs        | Decrypted bytes kept only in the local SQLCipher database (≤ 100 × 8 MB, images only); sending makes a fresh encrypted attachment; no outside GIF service is contacted | ✅ integration               |
| Group icons           | Inside the encrypted libsignal group update; only admins change it (checked on receipt as for names); length-capped; older apps strip the field                        | ✅ `dm.test.ts`              |
| Per-community picture | Kept locally and sent only in that community's sealed profile                                                                                                          | ✅ integration               |
| Avatar crop           | The chosen file is decoded with `createImageBitmap` and drawn on canvases; no URL of it enters the page (CodeQL clean); output validated by the avatar schema          | ✅ CodeQL, review            |
| Accessibility         | The favourite star is no longer nested inside the picture button (axe)                                                                                                 | ✅ `a11y.spec.ts`, e2e       |
| Screen share quality  | Capture constraints only; Electron's picker and permission handling unchanged                                                                                          | ✅ `screen-quality.test.tsx` |
| Followed threads      | Thread IDs in renderer storage; notices respect Do Not Disturb and quiet hours                                                                                         | ✅ `thread-follow.test.tsx`  |
| Forum pin/close       | Reuse the existing pin and thread-archive routes and their server checks                                                                                               | ✅ review                    |
| Slash commands        | Local text changes or existing actions (settings, nickname, poll, mute); unknown commands are sent as text                                                             | ✅ `slash.test.tsx`          |

No new metadata visible to the server. No critical issue is open for 1.0.25.
