# Security review — River 1.0.17

Scope: presence statuses and custom status, Markdown rendering, links from
messages, the emoji data, message links, quote and forward, new keyboard
shortcuts. Internal review; not an independent audit.

| Area                | Check                                                                                                                                                                                            | Result                                   |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------- |
| Links from messages | The renderer can only ask; main validates (http/https only, no embedded credentials, ≤ 2048 chars) and shows a native dialog with the punycode host and full address before `shell.openExternal` | ✅ `diagnostics-main.test.ts`, review    |
| Masked links        | The visible text never decides the destination; the confirmation shows the real URL; `javascript:`/`file:` never become links                                                                    | ✅ `rich-text.test.tsx`                  |
| Rendering           | Markdown, highlighting and timestamps render to React text nodes; no HTML strings, no `dangerouslySetInnerHTML`                                                                                  | ✅ review                                |
| Spoilers            | Hidden content is `aria-hidden` until revealed                                                                                                                                                   | ✅ `rich-text.test.tsx`                  |
| Custom status       | Inside the sealed community profile (AES-GCM, community key); the server stores only ciphertext; input length-capped and validated on read                                                       | ✅ integration test (no plaintext in DB) |
| Presence            | The server learns online/idle/DND (as before it learned online); invisible is enforced server-side for presence events and member lists; the status is sent with auth so it never flashes online | ✅ `communities.test.ts`                 |
| Message links       | Contain only opaque IDs; opening one in River only navigates within communities you are in; the server's `/channels/*` page is static, with a no-script CSP, and reveals nothing                 | ✅ `message-link.test.tsx`, review       |
| Forward             | Re-sends the text through the normal encrypted send path; attachments (and their keys) are not carried over                                                                                      | ✅ review                                |
| Emoji data          | Bundled emojibase JSON (MIT), loaded from the app itself; no network requests                                                                                                                    | ✅ review                                |
| Keyboard            | New shortcuts only change local UI state or settings                                                                                                                                             | ✅ `shortcuts.test.tsx`                  |

Residual risks unchanged. No critical issue is open for 1.0.17.
