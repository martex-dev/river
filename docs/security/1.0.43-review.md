# Security review — River 1.0.43

Scope: Tailscale Funnel as the hosting PC's public address, and SignPath code
signing in the release workflow. Internal review; not an independent audit.

| Area              | Check                                                                                                                                                                                                                                                                                   | Result                                            |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Funnel address    | Only a name from `tailscale status` that ends in `.ts.net` can become the public address; anything else is ignored                                                                                                                                                                      | ✅ `tailscale.test.ts`                            |
| What is exposed   | Funnel serves only `http://127.0.0.1:<server port>` (the River server); nothing else on the PC. TLS ends on the PC, so Tailscale relays see encrypted bytes only                                                                                                                        | ✅ `tailscale.test.ts` (exact command)            |
| Approval link     | The "allow Funnel" page link comes from Tailscale's own output in main, is opened only if it starts with `https://login.tailscale.com/`, and the renderer cannot pass a URL                                                                                                             | ✅ review, `host-manager.test.ts`                 |
| Members following | Moving to the Funnel address uses the same signed address notes as before; members accept only notes signed by the pinned server key                                                                                                                                                    | ✅ `host-manager.test.ts`, existing locator tests |
| Fallback          | If Funnel stops answering, a quick tunnel takes over; the honest status shows which one is in use                                                                                                                                                                                       | ✅ `host-manager.test.ts`                         |
| Code signing      | The signed installer replaces the unsigned one only by exact name; `latest.yml` and the block map are rebuilt from the signed bytes and checked; the workflow fails unless Windows reports the signature Valid. River's own Ed25519 release manifest is still made from the final files | ✅ `signed-installer.test.ts`, workflow           |
| Secrets           | SignPath token only as a GitHub secret; the signing step is skipped when it is not configured                                                                                                                                                                                           | ✅ workflow                                       |
| Honest claims     | README, CODE_SIGNING.md and the invite page say signing is pending until it is active; the invite page still explains the Windows prompt                                                                                                                                                | ✅ review                                         |

Residual risks: Funnel's bandwidth limits are not published; Tailscale (the
company) can see members' IP addresses and traffic volume, like Cloudflare
before it. No critical issue is open for 1.0.43.
