# Security review — River 1.0.23

Scope: export my data, sender-made link previews, moderator notes, reaction
notices, forwarding direct messages, and the guarded release tag script.
Internal review; not an independent audit.

| Area             | Check                                                                                                                                                                                                                                | Result                                                     |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| Data export      | Built in main from named columns only; never reads `identity.private_key`, `account.device_private_key`, `communities.key`, `signal_store` or sessions; deleted messages left out; written only where the person chooses             | ✅ `data-export.test.ts` (keys absent from the output)     |
| Export warning   | The UI says the file is not encrypted                                                                                                                                                                                                | ✅ review                                                  |
| Link previews    | Off by default; main fetches only http(s) URLs whose host resolves to public addresses (no loopback, private, link-local, CGNAT, multicast; `localhost`/`.local` refused); every redirect re-checked; 3 hops, 512 KB, 5 s, HTML only | ✅ `link-preview.test.ts`                                  |
| Preview content  | Parsed to plain strings, length-capped, sealed in the message; readers never fetch; shown only for a link present in the text; opening it uses the confirming link opener                                                            | ✅ integration, review                                     |
| Residual risk    | DNS can change between the check and the fetch (rebinding); the sender fetches with their own IP, which the setting explains                                                                                                         | ⚠️ documented                                              |
| Moderator notes  | Sealed with the community key (`note:<id>` AAD); listed, added and removed only by people who may time out, kick or ban; ≤ 50 per member; audited                                                                                    | ✅ `communities.test.ts`, integration (no plaintext in DB) |
| Reaction notices | Local; respect Do Not Disturb and quiet hours                                                                                                                                                                                        | ✅ `notify-rules.test.ts`                                  |
| DM forward       | Re-sends the text through the normal encrypted send path of the destination                                                                                                                                                          | ✅ review                                                  |

New metadata visible to the server: who wrote a note about whom and when. No
critical issue is open for 1.0.23.
