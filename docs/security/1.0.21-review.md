# Security review — River 1.0.21

Scope: message reports, ban with message deletion, role icons, cancel
upload, picture descriptions (alt text), member since. Internal review; not
an independent audit.

| Area          | Check                                                                                                                                                                                                                                                              | Result                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| Reports       | Reason and copy sealed with the community key (`report:<id>` AAD); the server lists a report only to people with `MANAGE_MESSAGES` in its channel and lets only them change its status; one report per person per message, ≤ 20 open per person; decisions audited | ✅ `communities.test.ts`, integration (no plaintext in DB) |
| Report trust  | The copy is the reporter's; the UI says so and offers the original message                                                                                                                                                                                         | ✅ review                                                  |
| Ban cleanup   | Needs `BAN_MEMBERS` and to outrank the target (unchanged); only the allowed windows (1 h … 7 days); deletes at most 1000 of the target's messages in that community, keeps thread counts right, tells viewers, audits the count                                    | ✅ `communities.test.ts`                                   |
| Role icons    | Inside the sealed role data; rendered as text; length-capped on read                                                                                                                                                                                               | ✅ integration (not in the server DB)                      |
| Alt text      | Sealed in the message body beside the pointers (older clients reject unknown pointer fields); only kept for attachments of that message; length-capped                                                                                                             | ✅ integration                                             |
| Cancel upload | Stops starting further uploads; an upload already sent is never linked to a message and the server's cleanup removes it                                                                                                                                            | ✅ review                                                  |
| Member since  | The day (never the time) someone joined, which the server already stored, shared with members                                                                                                                                                                      | ✅ `communities.test.ts`                                   |

New metadata visible to the server: who reported which message about whom,
and when. No critical issue is open for 1.0.21.
