# Security review — River 1.0.39

Scope: moving members between voice channels; documentation and parity
audit for the end of 1.0.x. Internal review; not an independent audit.

| Area          | Check                                                                                                                                                                                   | Result         |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- |
| Who can move  | The server requires the mover to outrank the person and to have Move members in both channels; the person must be allowed to see and connect to the destination; audited (`voice.move`) | ✅ server test |
| Full channels | A moved member gets a one-time pass for that channel only, valid 30 seconds, kept in server memory                                                                                      | ✅ server test |
| Older apps    | They receive the usual disconnect and simply leave the call; nothing is weakened for them                                                                                               | ✅ review      |

No new content visible to the server; it already knew who is in which voice
channel. No critical issue is open for 1.0.39.
