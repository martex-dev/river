# Security review — River 1.0.19

Scope: custom emoji, saved messages, ownership transfer, last channel per
community, long-message folding, copy River ID, and per-person voice
connection bars. Internal review; not an independent audit.

| Area               | Check                                                                                                                                                                                                                                | Result                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| Custom emoji       | Picture and name sealed with the community key (`emoji:<id>` AAD); the server stores ciphertext, a creator ID and a size-capped blob; `MANAGE_EXPRESSIONS` and the 100-emoji cap enforced on the server; creates and deletes audited | ✅ `communities.test.ts`, integration (no plaintext in DB) |
| Emoji rendering    | Images are decrypted data URLs drawn with `<img>`; names checked against `EMOJI_NAME`; `<:name:id>` only resolves to emoji of the current community; no network fetch                                                                | ✅ `custom-emoji.test.tsx`, review                         |
| Saved messages     | Kept only in the local SQLCipher database (migration v18); never sent to the server; removed with the account                                                                                                                        | ✅ `storage.test.ts`, review                               |
| Ownership transfer | Owner only, to a current member, server-authoritative; the previous owner becomes a member; audited as `community.transfer`                                                                                                          | ✅ `communities.test.ts`                                   |
| Connection bars    | Read from the local `RTCPeerConnection.getStats()`; nothing new leaves the device                                                                                                                                                    | ✅ `link-stats.test.ts`                                    |
| Last channel       | A channel ID per community in renderer storage; contains no content                                                                                                                                                                  | ✅ review                                                  |

New metadata visible to the server: the number and size of a community's
emoji, and who uploaded them (THREAT_MODEL §5h). No critical issue is open for
1.0.19.
