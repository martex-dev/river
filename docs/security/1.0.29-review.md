# Security review — River 1.0.29

Scope: community picture and banner, pinned messages in direct messages and
groups, call notices in conversations. Internal review; not an independent
audit.

| Area              | Check                                                                                                                                                            | Result                   |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| Community art     | Picture and banner are sealed with the community key (purpose `art`); changing them needs `MANAGE_COMMUNITY` on the server; the sealed blob is size-limited      | ✅ server test           |
| Art rendering     | Only `data:image/png`, `jpeg` or `webp` base64 URLs are shown (no SVG, no remote URLs), so a picture cannot run script or leak the viewer's address              | ✅ review                |
| DM and group pins | Sent as a libsignal message like edits and deletes; the server sees only an ordinary encrypted message. A pin applies only to a message in the same conversation | ✅ review                |
| Call notices      | Built on each device from its own local call history; nothing new is sent or stored on the server                                                                | ✅ `call-notes.test.tsx` |

No new metadata visible to the server. No critical issue is open for 1.0.29.
