# Security review — River 1.0.20

Scope: back/forward navigation, search filters and jump to date, quiet hours,
per-channel drafts, duplicate channel and role, custom emoji rename, emoji
favourites, server deafen, and manual input sensitivity. Internal review; not
an independent audit.

| Area              | Check                                                                                                                                                                                          | Result                                         |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| Search filters    | Parsed and applied on the device after decryption (`search-query.ts`); the server still only serves ciphertext history to members who can see the channel; queries never leave the device      | ✅ `search-query.test.ts`, integration         |
| Drafts            | Unsent text kept in renderer memory only, never written to disk or storage                                                                                                                     | ✅ `drafts.test.tsx`, review                   |
| Navigation        | History holds IDs only; going back to a channel or conversation that is gone is skipped                                                                                                        | ✅ `nav-history.test.tsx`                      |
| Quiet hours       | Local setting with a strict schema; only suppresses pop-ups and sounds                                                                                                                         | ✅ `notify-rules.test.ts`                      |
| Duplicate channel | Uses the normal create and update routes, so `MANAGE_CHANNELS` and overwrite validation apply on the server; the copy's name and topic are sealed with a fresh `channel:<id>` AAD; no messages | ✅ integration                                 |
| Emoji rename      | `PATCH /v1/emojis/:id` needs `MANAGE_EXPRESSIONS`, replaces only the sealed blob, is audited (`emoji.update`); unknown IDs 404                                                                 | ✅ `communities.test.ts`, integration          |
| Emoji favourites  | Emoji strings in renderer storage (like recents); no content                                                                                                                                   | ✅ `emoji.test.tsx`                            |
| Server deafen     | `voice.moderate.serverDeafened` needs `MUTE_MEMBERS` in that channel and must outrank the target; sticky through a rejoin; the deafened client stops sending and playing audio                 | ✅ `communities.test.ts` (sockets), mesh tests |
| Input sensitivity | A local gate on the outgoing track (`track.enabled`); off by default; nothing new leaves the device                                                                                            | ✅ `voice-gate.test.ts`, mesh tests            |

New metadata visible to the server: whether someone is server-deafened (like
server mute). No critical issue is open for 1.0.20.
