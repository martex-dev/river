# Security review — River 0.0.2

**Scope:** River server skeleton (`apps/server`), protocol package, desktop
Settings → Server. Internal review; not an independent audit.

| Area             | Check                                                                                                                                                                      | Result                                                                                          |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Logging privacy  | Fastify request logging replaced by a minimal line (method, route template, status, ms); pino `base: null`; `req`/`res`/headers redacted                                   | ✅ unit test with IP, query, auth header and user agent; CI greps container logs for client IPs |
| Error disclosure | 5xx bodies are generic; internal messages only in local logs                                                                                                               | ✅ unit test                                                                                    |
| Input limits     | 64 KiB body limit; 413 with uniform error                                                                                                                                  | ✅ unit test                                                                                    |
| Abuse            | Per-client rate limit, counters in memory only                                                                                                                             | ✅ unit test                                                                                    |
| Headers          | `nosniff`, `no-referrer`, `DENY`, CSP `default-src 'none'`, `no-store`; HSTS when a public https URL is set                                                                | ✅ unit tests                                                                                   |
| Proxy trust      | `X-Forwarded-For` ignored unless `RIVER_TRUST_PROXY=true`                                                                                                                  | ✅ default false                                                                                |
| Configuration    | Strict env validation, fails closed listing every problem; loopback bind by default                                                                                        | ✅ unit tests                                                                                   |
| Migrations       | One transaction per batch on SQLite and PostgreSQL; a failing migration leaves no partial schema                                                                           | ✅ found and fixed: Kysely did not use transactions on SQLite                                   |
| Container        | Non-root, read-only root FS, no capabilities, `no-new-privileges`, health check                                                                                            | ✅ CI runs the image that way                                                                   |
| Desktop → server | URL must be HTTPS (HTTP only to loopback), no credentials/query/fragment; responses capped at 16 KiB, 10 s timeout; response schema-validated; nothing about the user sent | ✅ unit + e2e against a real server                                                             |
| Settings upgrade | 0.0.1 settings files upgrade without being treated as corrupt                                                                                                              | ✅ unit test with the exact 0.0.1 shape                                                         |

## Residual risks

- Rate limiting is per IP; behind NAT many users share a limit, and without
  `RIVER_TRUST_PROXY` all users behind a reverse proxy share one. Per-account
  limits arrive with accounts (0.1.0).
- No TLS in the server itself — operators must terminate TLS in a proxy (documented).
